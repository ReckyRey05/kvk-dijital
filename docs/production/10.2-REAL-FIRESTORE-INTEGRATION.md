## 2. ATOMİK TRANSACTİON MİMARİSİ ([`firestoreOrderEngine.ts`](file:///c:/Users/ali_h/Desktop/Kvk%20Dijital/src/lib/restaurant/firestoreOrderEngine.ts))

`executeFirestoreOrderTransaction(db, input)` fonksiyonu tüm sipariş ve ödeme akışını Firestore'un yerel `db.runTransaction()` bloğu içinde koşturur:

```
1. t.get(idempotencyRef) -> Varsa mevcut siparişi döner (Sıfır mükerrer yazma).
2. t.get(tableRef) -> Masa durumunu ve restorana aidiyetini doğrular.
3. t.get(menuItemRef) -> Ürün fiyatını ve anlık stok durumunu okur.
4. Yetersiz stok varsa -> `throw new Error('OUT_OF_STOCK')` fırlatarak transaction'ı tamamen geri alır (Rollback).
5. Yeterli stok varsa -> `t.update(itemRef, { stock: current - qty })` ile atomik düşer.
6. t.set(orderRef, orderDoc) -> Siparişi yazar.
7. t.set(idempotencyRef, record) -> Anahtarı kilitler.
8. t.update(tableRef, { status: 'OCCUPIED' }) -> Masayı meşgul eder.
```
