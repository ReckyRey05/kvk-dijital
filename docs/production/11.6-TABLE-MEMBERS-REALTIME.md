# FAZ 11.6 — REALTIME TABLE MEMBERS / MASA ÜYELERİ MİMARİSİ VE KANIT DOKÜMANI

## 1. Mimari Genel Bakış
Cep Garson çok kullanıcılı masa oturumu (Group Dining / Shared Table Session) altyapısı, aynı fiziksel masaya oturan müşterilerin (`iPhone`, `Android`, tablet vb.) ve restoran personelinin (`Kasa POS`, `Garson Terminali`, `KDS Mutfak Ekranı`) anlık olarak aynı masa üye listesini tutarlı ve gerçek zamanlı görmesini sağlar.

## 2. Mevcut Session ve Üye Modeli
Sistemde her masa üyesi `TableParticipant` veri yapısı ile temsil edilir:

```typescript
export interface TableParticipant {
  id: string;                      // Benzersiz oturum kimliği (usr_timestamp_hash)
  name: string;                    // Görünen ad (Örn: "Masa Reisi", "Misafir 2", "Ali")
  isHost: boolean;                 // Masa Lideri mi? (true = Leader, false = Guest)
  status?: "APPROVED" | "PENDING_APPROVAL" | "REJECTED"; // Oturum onay durumu
  joinedAt: string;                // ISO 8601 katılım zaman damgası
}
```

## 3. Üye Rolleri ve Görünüm Temsili
- **Masa Lideri (Host / Reis):**
  - Masaya ilk katılan veya liderliği devralan kullanıcıdır.
  - Başında taç ikonu (`Crown`) ile gösterilir.
  - Sipariş onaylama ve grup ayarlarını yönetme yetkisine sahiptir.
- **Misafir (Guest):**
  - Masaya sonradan bağlanan kullanıcıdır.
  - Kullanıcı ikonu (`User`) ve sıra numarası (Örn: `Misafir 2`, `Misafir 3`) ile gösterilir.

## 4. Ekran Entegrasyonları

### 4.1. Müşteri QR Ekranı (`MenuHeader.tsx`)
- Üst barda aktif kişi sayısı rozeti yer alır (`Users` 3 Kişi).
- Rozete tıklandığında açılan popup/drawer penceresinde:
  - 👑 Ali (Masa Lideri • Siz)
  - 👤 Misafir 2
  - 👤 Misafir 3
  tüm üyeler anlık olarak listelenir.

### 4.2. Kasa POS Terminali (`TableGrid.tsx` & `BillManager.tsx`)
- **Masa Kartı Grid Görünümü:** Dolu masalarda üye sayısı ve lider adı anında görünür (`4 Kişilik • 👑 3 Üye (Ali)`).
- **Adisyon Paneli:** Masadaki tüm aktif üyeler etiket halinde gerçek zamanlı görüntülenir.

### 4.3. KDS Mutfak Ekranı (`KitchenCard.tsx`)
- Mutfak sipariş fişinde, hangi ürünün hangi masa üyesi tarafından sepete eklendiği (`item.addedBy`) ürün satırında açıkça belirtilir.

## 5. Duplicate Session ve Reconnect Önleme
- Bir istemci interneti kesilip tekrar bağlandığında veya sayfayı yenilediğinde, `localStorage`'da saklanan benzersiz `id` (`usr_...`) ile eşleşir.
- Sunucu ve yerel state yöneticisi, mevcut üyeyi `id` üzerinden günceller; duplicate üye eklenmesi `0` seviyesinde engellenir.

## 6. Table Close (Masa Kapatma) & Session Invalidation
- Kasa görevlisi masanın adisyonunu kapattığında (`CLOSE_TABLE_BILL`) veya masa sıfırlandığında:
  - `state.tableParticipants[tableId]` tamamen silinir (`delete`).
  - `state.sharedCarts[tableId] = []` boşaltılır.
  - Masaya bağlı tüm müşteri session'ları geçersiz kılınır.

## 7. Tenant Isolation (Çoklu Restoran İzolasyonu)
- Her restoranın masa ve üye listesi kendi bağımsız doküman alanında (`restaurants/{restaurantSlug}/liveSync/state`) tutulur.
- Çapraz restoran (cross-tenant) erişim girişimleri ve IDOR sızıntıları 100% izole edilmiştir.
