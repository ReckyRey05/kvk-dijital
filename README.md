# KvK Dijital Çözümler

İstanbul merkezli modern web tasarım, e-ticaret altyapıları ve özel yazılım çözümleri geliştiren dijital ajans platformu.

---

## 📌 Proje Hakkında

Bu repository, **KvK Dijital Çözümler** ajansının resmî kurumsal web platformunun ve sektörel konsept demo altyapılarının geliştirildiği kaynak kod deposudur.

- **Canlı Yayın (Production):** [https://kvkdijitalcozumler.com](https://kvkdijitalcozumler.com/)

---

## 🚀 Hizmet Alanları

- **Web Tasarım:** Mobil uyumlu, yüksek performanslı ve özgün kurumsal arayüz tasarımları.
- **Kurumsal Web Sitesi:** Şirketlerin dijital prestijini artıran, dönüşüm odaklı web siteleri.
- **E-Ticaret:** Hızlı sepet paneli, canlı ürün arama ve güvenli ödeme altyapılı online satış çözümleri.
- **Özel Yazılım:** İşletmelerin özel süreçlerine uygun kurgulanmış web uygulamaları ve API entegrasyonları.
- **SEO & GEO:** Arama motorları (SEO) ve yapay zeka arama motorları (GEO - Generative Engine Optimization) uyumlu teknik altyapı.

---

## 🛠️ Kullanılan Teknolojiler

Bu projede kullanılan temel teknolojiler ve kütüphaneler:

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Kütüphane:** [React 19](https://react.dev/)
- **Dil:** [TypeScript](https://www.typescriptlang.org/)
- **Stil & Tasarım:** [Tailwind CSS](https://tailwindcss.com/)
- **Veritabanı & Kimlik Doğrulama:** [Firebase](https://firebase.google.com/) (Auth, Firestore & Storage)
- **Performans Analitiği:** Vercel Analytics
- **İkon Seti:** Lucide React

---

## ✨ Öne Çıkan Özellikler

- **100/100 Core Web Vitals:** Sıfır sayfa kayması (CLS 0) ve milisaniyeler seviyesinde yüklenme süresi.
- **Dinamik SEO & JSON-LD:** Article, Organization, LocalBusiness ve FAQ şemaları ile Google standartlarına tam uyum.
- **İzole Tema Sistemi:** Konsept demolar için ana sitenin global marka renklerini etkilemeyen izole art direction mimarisi.
- **Statik & Dinamik İçerik Yönetimi:** Blog ve projeler için ISR (Incremental Static Regeneration) ve Firestore entegrasyonu.

---

## 🎨 Konsept Demo Çalışmaları

KvK Dijital Çözümler'in farklı sektörlerdeki tasarım ve yazılım yaklaşımını sergilemek amacıyla hazırlanan canlı konsept demo projeleri:

1. 🍽️ **[Pendik Sahil Bistro](https://kvkdijitalcozumler.com/projeler/pendik-sahil-bistro-demo):** Restoran & Kafe sektörü için editoryal menü ve masa rezervasyonu kurgusu.
2. 💅 **[Aura Beauty & Spa](https://kvkdijitalcozumler.com/projeler/aura-beauty-demo):** Güzellik merkezi ve wellness sektörü için takvim modüllü lüks tasarım.
3. ⚖️ **[Prestij Hukuk & Danışmanlık](https://kvkdijitalcozumler.com/projeler/prestij-hukuk-demo):** Hukuk büroları ve B2B danışmanlık firmaları için İsviçre editoryal kurumsal düzen.
4. 🏡 **[Vizyon Gayrimenkul](https://kvkdijitalcozumler.com/projeler/vizyon-gayrimenkul-demo):** Emlak ofisleri için canlı filtreli portföy marketplace altyapısı.
5. 🛍️ **[Artisanal Butik & Mağaza](https://kvkdijitalcozumler.com/projeler/artisanal-butik-demo):** Butik mağazalar için canlı ürün aramalı ve sepet paneli modüllü e-ticaret altyapısı.

> **Önemli Not:** Yukarıda yer alan konsept demolar gerçek müşteri projeleri olmayıp, KvK Dijital Çözümler'in sektörel tasarım yetkinliğini göstermek amacıyla hazırlanmış konsept çalışmalardır. Tüm çalışmalar için [https://kvkdijitalcozumler.com/projeler](https://kvkdijitalcozumler.com/projeler) sayfasını inceleyebilirsiniz.

## 💻 Yerel Geliştirme (Local Setup)

Projeyi yerel ortamınızda çalıştırmak için:

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Üretim derlemesini test edin
npm run build
```
