# KVK Digital — Logo Kullanım Rehberi

KVK Digital marka kimliğinde 5 farklı logo versiyonu bulunmaktadır. Logo kullanırken gereksiz varyasyon oluşturma; her alan için aşağıdaki belirlenmiş versiyonu kullan.

## Logo Dosyaları

### 1. `KVK-Digital-Logo-Primary.png`

**Ana / büyük logo**

Kullanılacağı yerler:

* Ana sayfanın Hero bölümü
* Marka tanıtım alanları
* Büyük bannerlar
* About / Hakkımızda bölümünün marka alanı
* Sunum veya kurumsal tanıtım bölümleri

Küçük alanlarda kullanma. Logo detaylarının rahat okunabileceği geniş alanlarda tercih et.

---

### 2. `KVK-Digital-Logo-Horizontal.png`

**Ana web sitesi logosu**

Öncelikli kullanım alanı:

* Navbar / Header
* Footer
* Web sitesinin genel marka alanları
* İletişim bölümü
* E-posta imzası veya kurumsal belgeler

**Navbar'da varsayılan olarak bu logo kullanılmalıdır.**

Logo yatay olduğu için header içerisinde genişlik açısından en uygun versiyondur.

---

### 3. `KVK-Digital-Logo-Square.png`

**Kare logo**

Kullanılacağı yerler:

* Instagram profil görseli
* WhatsApp Business profil görseli
* Sosyal medya profil alanları
* Kare format isteyen platformlar
* Uygulama benzeri marka alanları

Web sitesinin navbarında veya geniş yatay alanlarda kullanma.

---

### 4. `KVK-Digital-Logo-Circle.png`

**Yuvarlak logo**

Kullanılacağı yerler:

* Yuvarlak avatar alanları
* Profil görselleri
* Ekip / kullanıcı avatar alanları
* Küçük marka rozeti
* Watermark
* Yuvarlak UI bileşenleri

Web sitesinin ana logosu olarak kullanılmamalıdır.

---

### 5. `KVK-Digital-Logo-Icon.png`

**Sadece KVK sembolü**

Küçük alanlar için kullanılmalıdır.

Öncelikli kullanım alanları:

* Favicon
* Browser tab icon
* Mobil navbar
* Mobil menü
* Loading ekranı
* Küçük UI ikonları
* Hizmet kartlarında küçük marka sembolü
* 404 / Error sayfaları
* Dekoratif marka elementi

**Favicon için öncelikli logo budur.**

---

Antigravity aşağıdaki standardı uygulamalıdır:

| Site Alanı             | Kullanılacak Logo                 |
| ---------------------- | --------------------------------- |
| Navbar / Header        | `KVK-Digital-Logo-Horizontal.png` |
| Hero                   | `KVK-Digital-Logo-Primary.png`    |
| Footer                 | `KVK-Digital-Logo-Horizontal.png` |
| Favicon                | `KVK-Digital-Logo-Icon.png`       |
| Mobil Navbar           | `KVK-Digital-Logo-Icon.png`       |
| Loading Screen         | `KVK-Digital-Logo-Icon.png`       |
| 404 Sayfası            | `KVK-Digital-Logo-Icon.png`       |

## Şeffaf PNG Kullanımı

Aynı dosyaların `-Transparent.png` ile biten versiyonları şeffaf arka planlıdır.

Örneğin:

`KVK-Digital-Logo-Horizontal-Transparent.png`

Arka plan renginin logonun arkasında görünmesinin istendiği alanlarda **Transparent** versiyonu tercih edilmelidir.

### Örnek:

* Koyu arka plan → Transparent logo
* Görsel/video üzerine logo → Transparent logo
* Gradient arka plan → Transparent logo
* Açık renkli düz arka plan → uygun kontrast sağlayan logo versiyonu

## Tasarım Kuralları

* Logonun oranları kesinlikle değiştirilmemeli.
* Logo yatay/dikey olarak esnetilmemeli.
* Logo üzerine ekstra glow, shadow veya gradient eklenmemeli.
* Mevcut turkuaz renk değiştirilmemeli.
* Logonun çevresinde yeterli boşluk bırakılmalı.
* Çok küçük alanlarda Primary veya Horizontal logo kullanılmamalı; Icon tercih edilmeli.
* Logo, arka planla yeterli kontrasta sahip olmalı.
* Aynı bölümde birden fazla KVK logosu gereksiz yere kullanılmamalı.
* Logo tasarımı CSS ile yeniden oluşturulmamalı; mevcut PNG dosyaları kullanılmalı.

## Marka Önceliği

Genel kullanım sırası:

**Horizontal → Primary → Icon → Square → Circle**

Web sitesinde ana marka kimliğini oluşturan iki temel dosya:

`KVK-Digital-Logo-Horizontal.png`

ve

`KVK-Digital-Logo-Primary.png`

Diğer üç versiyon yalnızca kullanım alanına uygun olduğunda tercih edilmelidir.
